# RAPORT PONDOK AL-GHOZALI WEB

Aplikasi raport berbasis web untuk Pondok Modern Al-Ghozali.

## Prinsip
- Excel/Google Spreadsheet menjadi basis data di belakang sistem.
- Pengguna tidak melihat workbook sumber.
- Raport dirender langsung sebagai HTML/CSS.
- Layout diarahkan mengikuti format raport resmi yang diberikan.
- Siap dikembangkan ke autentikasi Guru, Wali Kelas, dan Admin.

## Jalankan
npm install
npm run dev

Buka http://localhost:3000
