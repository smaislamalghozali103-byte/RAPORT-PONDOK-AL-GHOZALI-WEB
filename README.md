# RAPORT PONDOK AL-GHOZALI WEB

Aplikasi raport berbasis web Pondok Modern Al-Ghozali.

## Status awal
- Repository baru.
- UI raport dibuat langsung di web, bukan menampilkan Excel.
- Struktur disiapkan untuk integrasi master siswa, guru, mapel, penugasan, nilai, dan cetak.
- Tahap berikutnya: integrasi Google Spreadsheet/Apps Script dan autentikasi.

## Jalankan
```bash
npm install
npm run dev
```

Buka http://localhost:3000
